# HH Авто-отклик Pro

Расширение Chrome, которое откликается на вакансии hh.ru за вас — и делает это разборчиво.

Обычный авто-откликер жмёт «Откликнуться» подряд по всей выдаче. Это расширение сначала читает данные, которые hh.ru отдаёт браузеру, но **не показывает в интерфейсе**: сколько человек уже откликнулось, требуется ли тестовое задание, сколько месяцев вакансию перевыкладывают, на месте ли рекрутёр. И только потом решает, стоит ли тратить один из 200 суточных откликов.

## Зачем это нужно

У hh.ru лимит 200 откликов в сутки. Вопрос не в том, как нажать кнопку 200 раз, а в том, **на что** эти 200 откликов потратить.

Замеры на живой выдаче `javascript` / Москва, 50 вакансий на странице:

| Что видно в выдаче | Что на самом деле |
|---|---|
| «Опубликовано сегодня» | у 11 вакансий из 50 разрыв между созданием и перепубликацией **больше месяца**, рекорд — 114 дней |
| Все вакансии выглядят одинаково | у 9 из 50 требуется **тестовое задание**, в карточке об этом ни слова |
| Сортировка «по соответствию» | медиана откликов у конкурентов **273**; с `order_by=publication_time` — **13** при том же охвате |
| Поиск по слову «javascript» | в выдачу попадает «Машинист экскаватора» — hh.ru ищет по всему тексту, а не по названию |

Расширение опирается на эти данные, а не на порядок карточек.

---

## Что расширение видит, а вы нет

hh.ru встраивает в каждую страницу выдачи JSON со всеми вакансиями. Там есть поля, которых нет в вёрстке карточки:

| Поле | Что даёт |
|---|---|
| `userTestPresent` | тестовое задание видно **до** отклика — 14 мс на всю страницу вместо загрузки каждой вакансии |
| `responsesCount` | реальная конкуренция за вакансию: очередь сортируется от наименее конкурентных |
| `creationTime` vs `publicationTime` | вечные вакансии: «сегодня» может значить «создана 4 месяца назад» |
| `employerManager.latestActivity` | у онлайн-рекрутёров медиана откликов 72 против 237 у офлайн |
| `@responseLetterRequired` | письмо обязательно — отправляется даже при выключенном сопроводительном |
| `keySkills` со страницы вакансии | в подстановку `{навыки}` попадают только те ваши навыки, что вакансия действительно просит |

Плюс серверные фильтры самого hh.ru, которые переносятся прямо в URL поиска: `search_field=name`, `label=not_from_agency`, `label=accredited_it`, `label=low_performance`, `work_format`, `experience`, `salary`, `search_period`. Сервер отдаёт уже отфильтрованную страницу — бот не выбрасывает 45 карточек из 50 после загрузки.

## Установка

Расширение не опубликовано в Chrome Web Store — ставится распакованным.

1. Скачайте `hh-auto-responder-v2.5.zip` со [страницы релизов](../../releases/latest) и распакуйте.
2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика** (справа вверху).
4. **Загрузить распакованное расширение** → выберите папку.
5. Откройте hh.ru — панель появится справа.

Нужен Chrome 111 или новее. Зависимостей у расширения нет: `npm` нужен только для сборки WASM и тестов.

## Настройки

Панель разбита на шесть вкладок.

**Фильтры** — приоритет очереди (меньшая конкуренция, онлайн-рекрутёр) и отсев: максимум откликов у вакансии, минимальная зарплата, свежесть, «сколько висит», формат работы, опыт, рейтинг работодателя и доля разбираемых им откликов. Там же чёрные и белые списки слов и организаций.

**Письмо** — шаблон с подстановками `{вакансия}`, `{компания}`, `{навыки}` и второй вариант для A/B-теста. Строка с незаполненной подстановкой выбрасывается целиком, чтобы работодателю не ушло «Мой опыт: {навыки}».

**Навыки** — ваш список, порог совпадения и точное сопоставление по странице вакансии.

**Поиск** — перенос фильтров на сторону hh.ru и очередь поисковых запросов: когда один исчерпан, бот переходит к следующему.

**hh.ru** — поднятие резюме в поиске (в том числе автоматически раз в 4 часа), избранное для пропущенных из-за теста, серверный чёрный список, импорт автопоисков.

**Ещё** — темп, ночной режим, конверсия, выгрузка в CSV, экспорт и импорт настроек.

## Конверсия

Кнопка «Конверсия» читает статусы откликов с hh.ru и показывает три разреза:

- **по варианту письма** — какой текст приносит приглашения;
- **по резюме** — считается по данным hh.ru, поэтому работает и для откликов, отправленных руками;
- **по конкуренции** — окупается ли сортировка: вёдра «до 20 / 20–50 / 50–200 / 200–500 / 500+».

Попутно собирается показатель «Разбирает N% откликов» — hh.ru показывает его только после отклика. Он привязан к работодателю, поэтому, узнав его один раз, бот отсеивает остальные вакансии той же компании.

## Защита от детектирования

Расширение подменяет ровно то, что нельзя перепроверить по заголовкам запроса, и **не трогает** то, что можно: User-Agent, язык, часовой пояс, память и число ядер берутся у настоящего браузера. Подмена того, что противоречило бы заголовкам, сама была бы маркером.

- Шум канваса и аудио, ширина текста и параметры WebGL считаются в WASM-модуле на 842 байта без единого импорта.
- Сид шума **постоянен для установки** и хранится в `chrome.storage`. Плавающий отпечаток выдаёт автоматизацию вернее, чем его отсутствие.
- Перехват ставится на `document_start`, до единого скрипта страницы. Профиль приезжает позже и лишь дополняет живой объект — перепатчивать ничего не нужно.
- Патчи маскируются под нативный код через `Function.prototype.toString`.
- `declarativeNetRequest` режет 22 рекламных и трекерных хоста.

Расширение не решает капчу. При появлении проверки бот **останавливается** и зовёт человека, а не долбится в неё перезагрузками.

## Разработка

```bash
npm ci            # только для сборки WASM и тестов
npm test          # тесты бота, защиты и WASM-модуля
npm run validate  # синтаксис JS/JSON и манифест
npm run build:wasm
npm run check:wasm  # сверяет protect.wasm с wasm/protect.wat побайтово
npm run pack        # собирает dist/hh-auto-responder-v2.5.zip
```

`protect.wasm` закоммичен, чтобы расширение ставилось без тулчейна. CI на каждом пуше пересобирает его из `wasm/protect.wat` и сверяет — несоответствующий исходнику бинарник в релиз не уедет.

Релиз собирается автоматически по тегу:

```bash
git tag v2.5 && git push origin v2.5
```

Версия в теге обязана совпадать с `manifest.json`, иначе сборка падает. Описание релиза генерируется из репозитория: список изменений из коммитов, состав архива из самого архива, SHA-256 считается на месте.

## Ограничения

- Только hh.ru и только Chrome 111+.
- Лимит 200 откликов в сутки держит hh.ru, а не расширение. Бот считает свои отклики и останавливается на 198.
- Если резюме скрыто от работодателя, hh.ru блокирует кнопку отклика — расширение это распознаёт и пропускает вакансию, но починить настройку видимости можно только в аккаунте.
- Показатель «Разбирает N% откликов» доступен только после первого отклика этой компании.

## Ответственность

Инструмент автоматизирует ваши собственные действия в вашем аккаунте. Отклики уходят от вашего имени — отвечаете за них вы. Заполните сопроводительное письмо и следите, куда именно бот откликается: по умолчанию поиск hh.ru идёт по всему тексту вакансии, а не по названию.
