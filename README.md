# ⚡ HH Авто-Отклик Pro v1.5.0 🛡️

Автоматический бот для откликов на вакансии HH.ru
с максимальной защитой приватности на базе WASM


## 📥 УСТАНОВКА

1. Скачайте файлы репозитория
2. Откройте chrome://extensions/
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное"
5. Выберите папку с файлами

## 🛡️ TECH GUARD — ЗАЩИТА ПРИВАТНОСТИ

5 уровней защиты:

| Уровень | Механизм |
|---------|----------|
| 1 | DNR правила (rules.json) — блокировка до загрузки |
| 2 | WASM модуль (C++) — нативная проверка URL |
| 3 | JS перехват API — контроль во время работы |
| 4 | Canvas/WebGL/Audio защита — фейковые отпечатки |
| 5 | Анти-детектор — мониторинг подозрительной активности |

## ⚡ WASM МОДУЛЬ (C++ → WebAssembly)

| Функция | Описание | Скорость |
|---------|----------|----------|
| should_block_request | Проверка URL | микросекунды |
| add_audio_noise | Шум в аудио | нативная |
| get_fake_webgl_param | Подмена GPU | нативная |
| JS fallback | Если WASM не загружен | миллисекунды |

Преимущества:
- Бинарный код нельзя прочитать
- Нативная скорость C++
- Автоматический fallback на JS

- Tech Guard + WASM активны всегда
- При ошибке WASM → автоматический JS fallback


## 🛠️ ПРОБЛЕМЫ

| Проблема | Решение |
|----------|---------|
| Не работает | Обновите страницу |
| Не откликается | Увеличьте задержку |
| Панель скрыта | Кнопка 🚀 справа |
| Extension invalidated | Перезагрузите страницу |
| Ошибка WASM | Работает JS fallback |
