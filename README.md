# ⚡ HH Авто-Отклик Pro v1.3

Автоматический бот для откликов на вакансии HH.ru


## 📥 УСТАНОВКА

1. Скачайте файлы репозитория
2. Откройте chrome://extensions/
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное"
5. Выберите папку с файлами

## 🎯 КАК РАБОТАЕТ АВТОВЫБОР РЕЗЮМЕ

1. Считывает название вакансии из модального окна
2. Открывает список всех ваших резюме
3. Сравнивает названия по умному алгоритму
4. Выбирает резюме с наивысшим процентом совпадения
5. Автоматически переключает на выбранное резюме

Алгоритм сравнения:

| Тип совпадения | Процент |
|----------------|---------|
| Точное совпадение названий | 100% |
| Название вакансии содержит название резюме | 95% |
| Название резюме содержит название вакансии | 90% |
| Сравнение по ключевым словам | до 90% |

Пример работы:

Вакансия: "Кладовщик приема и отправки ТМЦ"
Резюме:   "Кладовщик" → 95% совпадения → РЕЗЮМЕ ВЫБРАНО!


## 📋 ПОРЯДОК РАБОТЫ СКРИПТА

    1. Закрыть чат (если появился)
              ↓
    2. Выбрать лучшее резюме (если включено)
              ↓
    3. Найти поле для письма → заполнить → отправить
              ↓
    4. Найти "Добавить сопроводительное" → нажать → повторить
              ↓
    5. Найти "Все равно откликнуться" → нажать → повторить
              ↓
    6. Найти "Откликнуться" → нажать → отправить
              ↓
    7. Закрыть модальное окно


## ⚠️ ВАЖНЫЕ ПРАВИЛА

- Используйте настоящее имя в сопроводительном письме
- Начните с теста (кнопка "Тест на 1 вакансию")
- Не используйте задержку 0с — это может вызвать блокировку
- Откликайтесь релевантно — не спамьте
- Соблюдайте правила HH.ru


## 🛠️ РЕШЕНИЕ ПРОБЛЕМ

| Проблема | Решение |
|----------|---------|
| Не работает | Обновите страницу HH.ru и перезапустите расширение |
| Не отправляется отклик | Увеличьте задержку в настройках |
| Панель не видна | Нажмите на кнопку 🚀 в правом верхнем углу |
| Чат мешает работе | Скрипт автоматически закрывает его |
| Поле письма не заполняется | Убедитесь что галочка "Не отправлять" выключена |
| Не выбирается резюме | Проверьте порог совпадения, уменьшите до 50-70% |
