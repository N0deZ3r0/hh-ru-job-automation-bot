## 📥 УСТАНОВКА

1. Скачайте файлы репозитория
2. Откройте chrome://extensions/
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное"
5. Выберите папку с файлами

## 🛡️ ВСТРОЕННАЯ ЗАЩИТА

Многоуровневая система из 5 рубежей:

| Уровень | Механизм |
|---------|----------|
| 1 | Сетевой фильтр — блокировка до отправки запроса |
| 2 | Бинарное ядро — криптостойкая проверка |
| 3 | Контроль потоков — мониторинг активности на странице |
| 4 | Искажение отпечатков — графика, звук, железо |
| 5 | Маскировка — неотличима от обычного браузера |
