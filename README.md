# ⚡ HH Авто-Отклик Pro v1.4.0 🛡️

Автоматический бот для откликов на вакансии HH.ru
со встроенной защитой от сканирования 


## 📥 УСТАНОВКА

1. Скачайте файлы репозитория
2. Откройте chrome://extensions/
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное"
5. Выберите папку с файлами

## 🛡️ АНТИ-ФРОД (НОВОЕ В v1.4.0)

Трёхуровневая система защиты от сканирования портов:

| Уровень | Механизм | Срабатывание |
|---------|----------|--------------|
| 1 | declarativeNetRequest (rules.json) | До загрузки страницы |
| 2 | JS анти-фрод блок | При загрузке скрипта |
| 3 | Перехват API (XHR, fetch, WebSocket, EventSource) | Во время работы |

Перехватываются все каналы связи:

| Вектор | Статус |
|--------|--------|
| fetch | Заблокирован |
| XMLHttpRequest | Заблокирован |
| WebSocket | Заблокирован |
| EventSource | Заблокирован |
| sendBeacon | Заблокирован |
| Image.src | Заблокирован |
| setAttribute("src") | Заблокирован |
| iframe.src | Заблокирован |
| document.createElement(img) | Заблокирован |

Блокируемые адреса:
- 127.0.0.1
- localhost
- ::1
- 0.0.0.0

## 🎯 КАК РАБОТАЕТ АВТОВЫБОР РЕЗЮМЕ

1. Считывает название вакансии из модального окна
2. Открывает список всех ваших резюме
3. Сравнивает названия по умному алгоритму
4. Выбирает резюме с наивысшим процентом совпадения
5. Автоматически переключает на выбранное резюме

Алгоритм сравнения:

| Тип совпадения | Процент |
|----------------|---------|
| Точное совпадение названий | 100% |
| Название вакансии содержит название резюме | 95% |
| Название резюме содержит название вакансии | 90% |
| Сравнение по ключевым словам | до 90% |

Пример:

Вакансия: "Кладовщик приема и отправки ТМЦ"
Резюме:   "Кладовщик" → 95% совпадения → РЕЗЮМЕ ВЫБРАНО!


## 🛡️ КАК РАБОТАЕТ АНТИ-ФРОД

hh.ru использует систему SecurePortal для проверки пользователей:

1. Сканирование портов — проверяет открытые порты (RDP, VNC, SSH, TeamViewer)
2. Fingerprint — собирает цифровой отпечаток браузера
3. Трекеры — отправляет данные в Яндекс.Метрику, ВКонтакте, Mail.ru, TargetAds

Наша защита (трёхуровневая):

Уровень 1 — rules.json:
- Браузер блокирует запросы до загрузки страницы
- Фильтрует: xmlhttprequest, script, image, sub_frame, ping, websocket, other

Уровень 2 — JS анти-фрод блок:
- Перехватывает fetch, XHR, WebSocket, EventSource, sendBeacon
- Блокирует Image.src, iframe.src, setAttribute("src")

Уровень 3 — перехват API:
- Контролирует все динамические запросы во время работы


## 🎯 КАК РАБОТАЕТ АВТОФИЛЬТР

1. Ручной фильтр — вы сами добавляете организации в текстовое поле (через запятую)
2. Автофильтр — после успешного отклика организация добавляется в список
3. Прямые отклики — при обнаружении модалки "Вакансия с прямым откликом" организация добавляется в автофильтр
4. При следующем появлении этих организаций вакансии автоматически пропускаются

## ⚠️ ВАЖНЫЕ ПРАВИЛА

- Используйте настоящее имя в сопроводительном письме
- Начните с теста (кнопка "Тест на 1 вакансию")
- Не используйте задержку 0с — это может вызвать блокировку
- Откликайтесь релевантно — не спамьте
- Соблюдайте правила HH.ru
- 🛡️ Анти-фрод защита активна всегда, настроек не требует


## 🛠️ РЕШЕНИЕ ПРОБЛЕМ

| Проблема | Решение |
|----------|---------|
| Не работает | Обновите страницу HH.ru и перезапустите расширение |
| Не отправляется отклик | Увеличьте задержку в настройках |
| Панель не видна | Нажмите на кнопку 🚀 в правом верхнем углу |
| Чат мешает работе | Скрипт автоматически закрывает его |
| Поле письма не заполняется | Убедитесь что галочка "Не отправлять" выключена |
| Не выбирается резюме | Проверьте порог совпадения, уменьшите до 50-70% |
| Фильтр не блокирует | Убедитесь что галочка "Фильтровать организации" включена |
| Прямой отклик не пропускается | Убедитесь что "Автодобавление в фильтр" включено |
| Ошибки 127.0.0.1 в консоли | Защита активна, ошибки подавлены |
| Extension context invalidated | Обновите страницу после перезагрузки расширения |
| rules.json не работает | Проверьте что убрали "fetch" из resourceTypes |
