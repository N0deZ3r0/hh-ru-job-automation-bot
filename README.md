# ⚡ HH Авто-Отклик Pro v1.5.0 🛡️

Автоматический бот для откликов на вакансии HH.ru
с максимальной защитой приватности на базе бинарного модуля


## 📥 УСТАНОВКА

1. Скачайте файлы репозитория
2. Откройте chrome://extensions/
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное"
5. Выберите папку с файлами

## 🛡️ TECH GUARD — ЗАЩИТА ПРИВАТНОСТИ

Эшелонированная оборона из 5 рубежей:

| Уровень | Механизм |
|---------|----------|
| 1 | Фильтр на сетевом уровне — блокировка до отправки запроса |

| 5 | Маскировка защиты — система неотличима от обычного браузера |
