# ⚡ HH Авто-Отклик Pro v1.4.0 🛡️

Автоматический бот для откликов на вакансии HH.ru
с максимальной защитой приватности


## 📥 УСТАНОВКА

1. Скачайте файлы репозитория
2. Откройте chrome://extensions/
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное"
5. Выберите папку с файлами

## 🛡️ TECH GUARD — ЗАЩИТА ПРИВАТНОСТИ

4 уровня защиты:

| Уровень | Механизм |
|---------|----------|
| 1 | DNR правила (rules.json) — блокировка до загрузки |
| 2 | JS перехват API — контроль во время работы |
| 3 | Модификация заголовков — удаление x-fingerprint |
| 4 | try-catch изоляция — защита от падений |
