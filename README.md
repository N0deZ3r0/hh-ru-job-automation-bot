## 📖 ИСТОРИЯ

HeadHunter удалил видео. На нём был просто бот без защиты.

Теперь:
- 5 рубежей обороны
- 32 блокируемых домена
- 26 WASM-функций
- 11 перехваченных API
- 2 уровня изоляции (MAIN / ISOLATED)

Спасибо за мотивацию. У них — проблема.
