# ⚡ HH Авто-Отклик Pro v1.5.0 🛡️

Автоматический бот для откликов на вакансии HH.ru
с максимальной защитой приватности на базе WASM (WebAssembly)


## 📥 УСТАНОВКА

1. Скачайте файлы репозитория
2. Откройте chrome://extensions/
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное"
5. Выберите папку с файлами

## 🛡️ TECH GUARD — ЗАЩИТА ПРИВАТНОСТИ

5 уровней защиты:

| Уровень | Механизм |
|---------|----------|
| 1 | DNR правила (rules.json) — блокировка до загрузки |
| 2 | WASM модуль (C++/ChaCha20) — криптостойкая проверка |
| 3 | JS перехват API — контроль во время работы |
| 4 | Canvas/WebGL/Audio защита — фейковые отпечатки |
| 5 | Анти-детектор — мониторинг подозрительной активности |

## ⚡ WASM МОДУЛЬ (C++ → WebAssembly)

11 экспортированных функций:

| Функция | Описание |
|---------|----------|
| should_block_url | Проверка URL (30 портов + трекинг) |
| add_canvas_noise | Субпиксельный шум на Canvas |
| add_audio_noise | Частотно-зависимый шум со случайной фазой |
| get_fake_battery_level | Искажение уровня батареи |
| get_fake_webgl_vendor | Фиксированный фейковый вендор GPU |
| get_fake_webgl_renderer | Фиксированный фейковый рендерер GPU |
| get_fake_webgl_param | Фиксированные реалистичные параметры |
| get_fake_shader_precision | Фиксированная фейковая точность шейдеров |
| check_canvas_integrity | Реальная проверка целостности API |
| get_random_mode | Случайный режим защиты |
| get_random_int | Случайное число |

Преимущества:

- Криптостойкий ГСЧ (ChaCha20) — уникальный отпечаток для каждого пользователя
- Фиксация WebGL/Shader значений при первом вызове — неотличимо от реального GPU
- Бинарный код нельзя прочитать
- Нативная скорость C++
- Автоматический fallback на JS при ошибке загрузки
