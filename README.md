🔒 ЗАЩИТА ОТ ЦИФРОВОГО СЛЕДА
═══════════════════════════════════════════════════════════════

Графический холст (Canvas):
• Экспорт (toDataURL/toBlob) — WeakMap-кэш + TTL 5000ms
• Пиксели (getImageData) — WASM-шум (детерминированный)
• Альфа-канал — микро-шум

Видеочип (WebGL):
• Производитель (vendor) — подмена на Google Inc. (NVIDIA/AMD/Intel)
• Модель (renderer) — при первом запуске случайная из 9 вариантов:
  - NVIDIA: RTX 3060, 3070, 3080, 4060
  - AMD: RX 6700 XT, 6800 XT, 7600
  - Intel: Iris Xe Graphics, UHD Graphics 630
• Затем фиксируется навсегда (chrome.storage.local)
• Параметры — 12 параметров через getFakeWebGLParam
• WEBGL_debug_renderer_info — скрыто, getExtension возвращает null

Звуковой профиль (Audio):
• AudioContext sampleRate: 48000
• Идентификаторы устройств — enumerateDevices → очистка label

Параметры браузера (Navigator):
• 11 свойств: platform (Win32), hwConcurrency (8), deviceMemory (16),
  vendor (Google Inc.), language (ru-RU), languages (['ru-RU','ru']),
  webdriver (false), userAgent (Chrome 148), maxTouchPoints (0),
  doNotTrack ('1'), pdfViewerEnabled (true)

Временные метки:
• performance.now с джиттером ±0.1ms

Хранилище трекеров:
• Автоочистка _tads, __gti__, __zzat, __lpct, __est__

Глобальные объекты слежки:
• Object.defineProperty на _txspjs, _txq

Client Hints:
• userAgentData: brands Chromium 148, platform Windows, mobile false

WebRTC:
• Фильтрация приватных IP, перехват onicecandidate

Battery API:
• Не подменяется (undefined — норма для Chrome 120+)
